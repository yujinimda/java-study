# 자바의 정석 스터디 — 손으로 쓰고, 컴파일해서 확인하기

『Java의 정석 3판』(남궁성) **1장 ~ 7장 (객체지향까지)** 를 10단계로 나눠서 진행합니다.
IDE 없이 `javac` / `java` 만 씁니다. 컴파일 에러를 직접 읽는 게 이 스터디의 핵심입니다.

## 학습 루프 (매 단계 이걸 반복)

```
① 책 읽기        지정된 절을 읽는다. 코드는 아직 타이핑하지 않는다.
② 손으로 정리    plan 파일의 "손으로 정리할 것" 을 노트에 직접 쓴다.
③ 문제 풀기      "출력 예상 문제" 를 노트에 손으로 답을 적는다. (컴파일 금지)
④ 손코딩        "손코딩 과제" 를 종이에 먼저 다 쓴다. 세미콜론, 중괄호까지.
⑤ 타이핑        종이에 쓴 걸 src/stepNN/ 에 그대로 옮긴다. 고치지 말고 그대로.
⑥ 컴파일        ./run 으로 돌린다. 에러가 나면 notes/errors.md 에 적는다.
⑦ 대조          ③④ 의 내 답과 실제 결과를 비교한다. 틀린 것만 answers/ 를 본다.
```

⑤에서 **종이에 쓴 걸 고치지 않고 그대로 옮기는 것**이 중요합니다. 머리로 틀린 부분이
컴파일 에러로 튀어나오는데, 그게 가장 잘 남는 학습입니다.

## 사용법

```bash
./run step01/Hello.java          # src/step01/Hello.java 컴파일 + 실행
./run answers/step01/Step01Answers.java   # 모범답안 실행
```

`./run` 은 **지정한 파일 + 그 파일이 참조하는 같은 폴더의 클래스**만 컴파일합니다.
그래서 클래스를 여러 파일로 나눠도 알아서 되고, 옆에 **일부러 망가뜨린 파일이 있어도
방해받지 않습니다.** (step00 과제 2에서 필요합니다)

`package` 선언은 7장에서 배우기 전까지 쓰지 않습니다.

## 폴더

| 경로 | 용도 |
|---|---|
| `plan/stepNN.md` | 그 단계에서 **읽을 것 · 문제 · 과제**. 여기서 시작. |
| `src/stepNN/` | 내가 코드를 쓰는 곳 |
| `answers/stepNN.md` | 문제 정답과 해설 |
| `answers/stepNN/` | 손코딩 과제 모범답안 (컴파일 가능) |
| `notes/errors.md` | 내가 만난 컴파일 에러 모음 — 이게 제일 값어치 있는 파일이 됩니다 |
| `reference/` | 참고 자료 (책 그림과 실제 환경이 다를 때 등) |

  들어 있습니다. 각 단계의 글은 `plan/stepNN.md` 「읽을 것」에도 직접 링크돼 있습니다.

> step04부터(배열 · 객체지향) 만듭니다. 진행 속도를 보고 난이도를 조절하려고 일부러
> 다 만들어두지 않았습니다.

## 진행 속도

한 단계에 **3~5일, 하루 40분** 정도를 기준으로 잡으세요. step05부터(객체지향)는
한 단계에 1주씩 써도 됩니다. 빠르게 가는 게 목적이 아니라, 손이 문법을 외우는 게 목적입니다.

막히면 그냥 물어보세요. 답을 주기 전에 어디서 막혔는지부터 같이 봅니다.
