# 내가 만난 컴파일 에러 모음

에러가 날 때마다 아래 형식으로 쌓아두세요. 같은 에러를 두 번째로 만났을 때
"아 이거 봤는데" 하고 스스로 고치게 되는 게 목표입니다.

형식:

```
## <에러 메시지 첫 줄>
- 언제: stepNN / 파일명
- 원인:
- 고친 방법:
```

---

## 예시 (지우고 쓰세요)

```
## Hello.java:3: error: ';' expected
- 언제: step00 / Hello.java
- 원인: System.out.println 뒤에 세미콜론을 안 붙였다
- 고친 방법: 세미콜론 추가. 에러가 가리킨 줄 번호가 3인데 실제로 빠진 건 2번 줄이었다.
             컴파일러는 "빠진 걸 알아챈 위치"를 알려주므로 한 줄 위도 봐야 한다.
```
